# Code of Conduct

## Our Standard

ATLARS is a professional open-source project. Contributors are expected to act with the same professionalism they would bring to any serious technical environment.

**Expected behavior:**
- Communicate clearly and respectfully
- Give and receive technical feedback without making it personal
- Acknowledge when you don't know something
- Help other contributors when you can

**Unacceptable behavior:**
- Personal attacks, insults, or demeaning comments
- Harassment of any kind
- Dismissing contributors based on experience level, background, or identity
- Sharing others' private information without consent
- Sustained disruptive behavior in issues, PRs, or discussions

## Enforcement

Violations are reported to: conduct@thehustlehouseofficial.com

Maintainers have full discretion to remove any contributor from the project for violations of this standard. There is no appeal process for harassment.

## Scope

This applies to all project spaces: GitHub issues, PRs, Discussions, and any other communication in the context of this project.
